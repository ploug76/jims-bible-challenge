# Jim's Bible Challenge
A Scripture memory card game. Play: https://ploug76.github.io/jims-bible-challenge/

Scripture quotations: King James Version (public domain). Verse text was fetched from bible-api.com (`?translation=kjv`) and cross-checked against the public-domain KJV datasets scrollmapper/bible_databases (KJV.json) and aruljohn/Bible-kjv. Long verses are shortened on cards only at a natural clause break, marked with an ellipsis (…); the full verse is shown on a 5-point match.
